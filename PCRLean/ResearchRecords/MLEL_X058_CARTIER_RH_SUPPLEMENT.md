# MLEL-X058 Supplement

## Cartier--Riemann--Hilbert Transport and Constructible No-Reset

### Standard categorical input

For separated finite-type schemes over a perfect field, the Cartier--Riemann--Hilbert correspondence identifies coherent Cartier crystals with perverse constructible F_p-sheaves. In the form used in X058 it is compatible with intermediate extension and derived proper pushforward.

The proof uses only the anti-equivalence, exactness on the hearts, proper-pushforward compatibility, intermediate extension, and finite length. It does not invoke semisimplicity or a decomposition theorem.

### One model-independent event category

For every centre-exact model `W_w`, the complete Cartier state and event triangles are pushed to the initial model before applying the solution functor. All terms then lie in one constructible category. The finite exactified grammar and finite support stratification give one perverse ancestor `P_0` containing every transported state and event as a subquotient.

### Canonical primitive identity

A primitive event is a local system `L` on its maximal smooth stratum. The intermediate extension `j_!* L[dim]` is its global identity. Chart restrictions, common refinements, and irreducible chart components are aliases. An inherited return is already contained in the consumed subobject.

### Consumed subobject and finite length

Let `D_i subset P_0` be generated by all primitive factors discharged before stage `i`. A truly new event is nonzero in `P_0/D_i`, hence strictly enlarges `D_i`. The labelled Jordan--Holder multiset of the residual object strictly decreases.

### Compatibility with actual centres

The constructible category does not contain the ideal defining the centre. The algebraic Cartier--Rees state supplies Fitting supports and Rees algebras. Proper-pushforward compatibility identifies the algebraic and constructible event factors, so a centre acting on maximal residual algebraic support consumes the corresponding maximal residual perverse factors.

### Firewalls

The following are rejected:

- comparing lengths of unrelated crystals on successive schemes;
- assuming perverse F_p-sheaves are semisimple;
- using intermediate extension to choose an algebraic centre;
- counting chart restrictions as distinct simple factors;
- discarding extension classes through a decomposition theorem;
- allowing a new chamber to reset the constructible coordinate at the same earlier rank.

The X058 rank is lexicographic: a chamber change occurs only after an earlier geometric coordinate has already decreased.
