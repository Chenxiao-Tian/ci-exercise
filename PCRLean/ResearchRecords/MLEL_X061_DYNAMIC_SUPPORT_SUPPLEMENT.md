# MLEL-X061 Supplement

## Dynamic Generic Support Quotients and First-Failure Descent

### Why finite monodromy is unnecessary

Finite stratification does not imply that every future local system factors through one finite quotient of the etale fundamental group. X061 does not attempt to prove this. At each stage it uses only the particular finite-length object already present in the generic support quotient.

### First-failure principle

For a comparison morphism in a bounded nondegenerate t-structure, isomorphisms on all t-cohomology objects imply an isomorphism. Decomposing each perverse kernel and cokernel by maximal irreducible support shows that a nonzero comparison has a first nonzero generic-support failure.

Thus a changed local system or changed extension class is visible through the actual comparison morphism; it need not be listed in advance.

### Strict epimorphic descent

The complete centre block eliminates the Cartier-dual leading quotient generically. After universal exactification the generic successor map is an epimorphism. At fixed perverse degree and support, nonterminality forces a nonzero kernel, so finite length falls.

### Lower support births

No-upward-birth and source conservation show that a newly visible lower event is supported properly inside a removed leading support and carries the same finite ancestor source join. This is exactly the replacement condition in the Dershowitz-Manna multiset order.

### Extension classes

No semisimplicity or decomposition theorem is used. If the comparison map is a nonisomorphism caused only by changed extension data, its cone is nonzero and the first-failure principle produces a perverse kernel or cokernel at some generic support.
