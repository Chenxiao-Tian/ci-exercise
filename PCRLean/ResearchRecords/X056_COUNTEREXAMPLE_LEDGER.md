# X056 Counterexample and Defensive-Clause Ledger

1. A radicial extension must not be tied to one equation `z^p=a`; changing generators can change the visible coefficient system. X056 uses the intrinsic relative foliation and the full Hasse algebra.
2. An arbitrary ideal upstairs does not descend through a ramified finite morphism. X056 descends only full-Hasse-stable ideals and retains the complete Rees comparison.
3. A normalized blowup is not an allowed final step. Norm-Rees terminalization uses normalized source models only to compare fans; the base is modified by ordinary blowups in regular centres.
4. A common fan regular in two finite-index lattices is not taken as an independent black box. X056 regularizes the source through base norm ideals and source multiplicity descent.
5. A differential-zero unit cannot simply be discarded. It is absorbed only after the smooth p-constant lemma proves that it is a pth power.
6. A defectless projection is not used to choose centres. It is selected only after an infinite intrinsic sequence is assumed and a witness valuation is extracted.
7. Riemann-Zariski compactness does not patch arbitrary local resolutions. In X056 it is used only to obtain a valuation in nested nonterminal cylinders.
8. Normalization, alteration, weighted, stacky, and derived modifications never replace the final ordinary blowup sequence.
