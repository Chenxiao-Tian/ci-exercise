# X065 Supplement: Source-Normalized Recurrence

## Label firewall

A raw exceptional divisor is not an independent resource. Its essential label contains only:

```text
owner set;
primitive ancestry subquotient;
ordered boundary incidence;
bounded Tor/conductor/contact/augmentation debt.
```

The same label is used in gauge equivalence and in strong alternating bisimulation. A newly created exceptional divisor receives no fresh serial label.

## Strict object

For each essential label, fix the finite-length ancestor object `U_lambda`. Let `D_i,lambda` be the subobject generated by already consumed primitive events. The residual rank is the labelled Jordan--Holder multiset of `U_lambda/D_i,lambda`.

A completed nonterminal block either lowers earlier geometry, moves to a proper support or lower-dimensional exceptional face, or gives

```text
D_i,lambda proper_subset D_(i+1),lambda.
```

This is the load-bearing descent. The statements that a nonterminal gauge return is impossible and that every idempotent size-change graph has a strict self-loop are consequences, not replacements, of this geometric strictness.

## Compatibility

Chart copies and inherited returns map to already consumed source subobjects. Owner and boundary information is retained through finite incidence types, while the raw name of an exceptional component is discarded. Consequently the gauge groupoid and the finite recurrent quotient live in one and the same labelled category.
