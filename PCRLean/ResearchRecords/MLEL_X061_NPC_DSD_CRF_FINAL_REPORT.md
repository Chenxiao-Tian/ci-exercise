## Executive synthesis

X060 supplied several complementary ways to place the categorical termination argument in a fixed setting: finite support quotients, finite monodromy envelopes, finite derived gluing spaces, and intrinsic coniveau profiles. X061 removes the two strongest global finiteness hypotheses from the load-bearing proof.

1. No global finite set of future supports is chosen. Every individual transported state has finite length and therefore only finitely many generic supports.
2. No common finite etale cover killing every future local system is required. The proof uses only the finite length of the local-system object currently present in the generic support quotient.
3. No universal finite-dimensional space enumerating every future Postnikov or recollement extension class is required. A nonzero comparison cone has a first failure in perverse cohomology and generic support; if all induced maps were isomorphisms, nondegeneracy of the perverse t-structure would make the comparison an isomorphism.
4. Irreducible closed supports are ordered by strict inclusion. Because the initial model is Noetherian, this order is well founded. The bounded perverse degree and the Dershowitz-Manna multiset extension give a global dynamic support order.
5. At the maximal active support antichain, the actual-centre word makes the successor map an epimorphism in every relevant Serre quotient. Nonterminality forces either a lower degree, a proper-support move, or a nonzero kernel. In the last case finite length strictly decreases.
6. A change of local monodromy or of a derived extension class cannot evade the rank: it must make one generic comparison map nonisomorphic, hence produce a first-failure kernel or cokernel.
7. Cartier-Riemann-Hilbert remains contravariant. The perverse kernel is matched to the algebraic Cartier quotient whose coherent Fitting support supplies the actual centre. Constructible supports never choose centres by themselves.

Under the X061 assumption this yields principalization, ordinary strong embedded resolution, ambient independence, intrinsic resolution, and smooth functoriality over perfect fields of positive characteristic.

## 1. Dynamic generic support categories

Let

```text
P = Perv_c(W_0,et,F_p).
```

For every irreducible closed subset `Z subset W_0`, define

```text
Q_Z = P_(<=Z) / P_(<Z),
```

where the denominator is the Serre subcategory generated by proper closed supports in `Z`. For a perverse object `P`, its generic component at `Z` is the image in `Q_Z`.

Every object of `Q_Z` has finite length. Its simple constituents are intermediate extensions from a dense smooth open in `Z`. No assertion is made that the collection of all possible local systems is finite.

A finite-length object has only finitely many nonzero generic components. Thus the dynamic support cycle

```text
Xi(K) = multiset over (q,Z) of length_QZ(gamma_Z(pH^q K))[(q,Z)]
```

is finite for every transported bounded complex `K`.

## 2. Noetherian support order

Order pairs by

```text
(q',Z') < (q,Z)
iff q'<q, or q'=q and Z' proper_subset Z.
```

The perverse amplitude lies in a fixed finite interval. A Noetherian topological space has no infinite strictly descending chain of closed subsets. Hence this order and its finite multiset extension are well founded.

This replaces a global support atlas, a total ordering of strata, and a frozen future support poset.

## 3. First-failure theorem

Let `f:K'->K` be a morphism in the bounded constructible derived category. If every map on every perverse degree and every generic support quotient is an isomorphism, then the kernel and cokernel of every perverse cohomology map have zero generic quotient on every maximal irreducible component of their support. They are therefore zero. Nondegeneracy of the perverse t-structure implies that `f` is an isomorphism.

Consequently every nonzero event has a maximal first-failure pair `(q,Z)`. This detects a new local-system type, changed monodromy, changed Postnikov invariant, changed recollement extension, or chart/common-refinement mismatch. A separate finite Ext-coordinate or finite-monodromy budget is unnecessary.

## 4. Simultaneous maximal-antichain realization

At the highest nonzero perverse degree, take every support maximal by inclusion. This finite set is an antichain. Cartier-Riemann-Hilbert duality matches its generic perverse quotients with residual algebraic Cartier-Rees quotients. Their maximal coherent Fitting supports, all scheme-theoretic intersections, and the complete active, passive, contact, source, and boundary data form one finite coloured portfolio.

The actual-centre theorem resolves the whole antichain simultaneously by ordinary blowups in regular jointly legal centres. No support, chart, minimizer, or symmetry orbit is selected arbitrarily.

## 5. Strict dynamic event descent

For the transported event triangle

```text
K_(i+1) -> K_i -> E_i -> K_(i+1)[1],
```

assume that the earlier geometric rank is unchanged. Universal exactification makes the leading map an epimorphism in each maximal generic quotient. Nonterminality and first-failure detection imply one of:

1. the highest nonzero perverse degree decreases;
2. every successor maximal support is properly contained in an old maximal support;
3. at an unchanged maximal support `Z`, the generic quotient map has a nonzero kernel.

In the third case the finite length at `(q,Z)` strictly decreases. Every lower-layer birth is financed by and supported properly inside a removed leading support. Hence the dynamic support cycle strictly decreases in the Dershowitz-Manna multiset order.

## 7. Smooth functoriality

For a smooth morphism of pure relative dimension `d`, the normalized functor is `g^dagger=g^*[d]`. It is perverse t-exact, preserves strict support inclusion, and commutes with intermediate extension. Pullback may split one support, but the projection groupoid identifies the components as aliases of one source-labelled object. Exact pullback preserves a nonzero leading kernel on every nonempty component.

The actual algebraic portfolio commutes with the same base change. Thus the centre word and the dynamic descent theorem are compatible with open restriction, smooth/etale morphisms, and perfect-field extension.
