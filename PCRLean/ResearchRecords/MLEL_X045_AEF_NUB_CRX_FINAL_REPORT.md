## 0. Executive verdict

1. Event complexes compose by a canonical octahedral triangle. For composable completed centre words `u` and `v`,

   ```text
   Her_v Ev_u(Sigma)
      -> Ev_(vu)(Sigma)
      -> Ev_v(Sigma_u)
      -> Her_v Ev_u(Sigma)[1].
   ```

   Hence a cumulative event is an iterated extension of the transported one-step events. It is not a new unrelated object at every stage.

2. Every coloured state and every event cone carries a filtration by the finite join semilattice generated by the immutable incoming source IDs. The primitive quotient at a join `A` is

   ```text
   Prim_A(E)=F_A E / sum_(B<A) F_B E.
   ```

   This gives a canonical, symmetry-invariant source identity. Chart components and decompositions are manifestations of one primitive packet rather than new source clones.

3. A source-closed X044 actual-centre block cannot create a new root source. Every nonzero primitive successor event is either:

   ```text
   SOURCE_MERGE:
       its support label is the join of two or more incoming ancestors;

   FINANCED_REAPPEARANCE:
       it has a previously existing primitive source label and is the same
       canonical token with a lower local profile;

   EARLIER_GEOMETRIC_DROP:
       its carrier dimension, support dimension, projective contact height,
       Tor-Valabrega-Fitting profile, Frobenius/radicial profile, or

   ```

   Thus the AFPM fresh-root-birth countermodel is excluded in the finite coherent sector.

4. The complete X044 portfolio yields a no-upward-birth theorem for coherent recurrent classes. A block chosen for a maximal coherent token replaces it on every nonterminal chart only by coherent tokens strictly below it in one fixed order. If a successor event had the same complete profile, every prepared comparison map would be an isomorphism, every monomial face would already be discharged, and the event cone would vanish.

5. The finite multiset of live coherent recurrence tokens therefore decreases in the Dershowitz--Manna multiset extension. This gives finite termination of the coherent recurrent subgame, including all finite trace, pure-Frobenius, projective-direction, owner-conflict, support-thickness, and Tor-Valabrega packets admitted by the complete coloured grammar.

6. Consequently every hypothetical infinite branch must eventually carry a genuine noncoherent valuation/immediate-defect token. The remaining universal geometric obstruction is no longer a mixture of finite births and coherent recurrent classes. It is the uniform immediate-defect escape theorem on a quasi-compact valuation neighbourhood, followed by finite globalization.

General arbitrary-dimensional positive-characteristic resolution is not established. The X045 theorem is conditional on the lower-dimensional full-portfolio induction and on semantic completeness of the X044 finite coherent colour grammar; it removes the ancestral-birth and coherent-recurrence burden under those hypotheses.

## 1. Event composition and the octahedral filtration

Let `P(Sigma)` be the bounded coherent presentation complex of the complete coloured state. Let

```text
u : Sigma_0 -> Sigma_1,
v : Sigma_1 -> Sigma_2
```

be completed centre-exact words. Write

```text
h_u  : Her_u P(Sigma_0) -> P(Sigma_1),
h_v  : Her_v P(Sigma_1) -> P(Sigma_2).
```

The comparison for the composite is

```text
h_(vu)=h_v o Her_v(h_u).
```

Define

```text
Ev_u(Sigma_0)=Cone(h_u),
Ev_v(Sigma_1)=Cone(h_v),
Ev_(vu)(Sigma_0)=Cone(h_(vu)).
```

### Theorem 1.1 -- Event-octahedron theorem

There is a distinguished triangle

```text
Her_v Ev_u(Sigma_0)
  -> Ev_(vu)(Sigma_0)
  -> Ev_v(Sigma_1)
  -> Her_v Ev_u(Sigma_0)[1].
```

### Proof

Apply the octahedral axiom to the composable morphisms

```text
Her_v Her_u P(Sigma_0)
   --Her_v(h_u)--> Her_v P(Sigma_1)
   --h_v--> P(Sigma_2).
```

The three mapping cones are the stated event objects. The construction is natural for exact hereditary transport and is compatible with open restriction and smooth/etale base change.

### Corollary 1.2 -- Telescoping event filtration

For a finite chain of blocks `w_1,...,w_n`, the cumulative event complex

```text
Ev_(w_n...w_1)(Sigma_0)
```

has a finite filtration in the triangulated extension closure whose graded factors are the transported one-step events

```text
Her_(w_n...w_(i+1)) Ev_(w_i)(Sigma_(i-1)).
```

Thus a later event records an extension of all previous novelty and the current one-step novelty. It does not erase ancestry.

## 2. Finite source join semilattice

Let `S_0` be the finite set of immutable root source IDs in the current outer induction atom. Let `L(S_0)` be the finite join semilattice of nonempty source supports generated by `S_0`. A join is written `A vee B`.

Every coloured component of `P(Sigma)` carries one support label in `L(S_0)`. Operations used in the portfolio are source monotone:

```text
direct sum:         support is recorded componentwise;
tensor/product:     support is the join;
kernel/image/coker: inherited support;
Hasse/Frobenius:    inherited support;
Fitting layer:      inherited support;
Rees and Sym:       join of coefficient supports;
centre block:       join of the colours used by the centre;
exceptional trace:  the same incoming support, not a fresh root.
```

For `A in L(S_0)`, let `F_A P` be the subcomplex generated by components whose source support is `<= A`. All hereditary and intrinsic comparison maps preserve this filtration.

### Definition 2.1 -- Primitive event packet

For an event complex `E`, define the primitive source quotient

```text
Prim_A(E)=F_A E / sum_(B<A) F_B E.
```

The sum is taken inside the source-filtered complex. Its cohomology and intrinsic Fitting layers are the primitive birth packet at support `A`.

### Theorem 2.2 -- Finite root-source theorem

Along every sequence of source-closed X044 blocks, every nonzero primitive event is labelled by an element of the original finite semilattice `L(S_0)`. No new root source ID is created by a chart, exceptional divisor, cleaning, saturation, normalization, or event-cone decomposition.

### Proof

The statement holds at the initial state. Every construction of a centre and every successor portfolio operation is obtained from source-monotone operations on incoming colours. Hence source labels can only be inherited or joined. X044 source closure gives the same assertion for internal centres and exceptional components. The event cone is formed from a source-filtered map and therefore inherits the filtration. Induction on the number of blocks proves the claim.

### Corollary 2.3 -- No split/no clone at identity level

A decomposition of a primitive event sheaf into chart pieces or irreducible components does not create several source identities. All pieces remain one globally descended primitive packet with the same tuple

```text
(source join, colour, cohomological degree, Fitting layer).
```

If a packet decomposes into smaller source supports, those pieces occur in lower primitive quotients and are not clones of the original support.

## 3. Coherent recurrence tokens

A coherent recurrence token is a tuple

```text
tau=(class, source support, colour, carrier, profile, gates, provenance)
```

where the carrier is a coherent finite-type packet on a finite model. The finite coherent classes include:

```text
T  consumed trace and exceptional history;
P  pure Frobenius/content recurrence;
D  projective Hasse direction and nilpotent contact;
```

A genuine immediate-defect valuation pro-end is not a coherent token and is kept in the separate class `V`.

Define the coherent profile

```text
rho_coh(tau)=
  (carrier dimension,

   Tor-Valabrega-Fitting profile,

   monomial-face height,
   source-join height,
   local word height).
```

Each coordinate is a finite well-founded value or a finite multiset with its standard multiset order. The class priority is inserted before the class-specific tail when needed.

## 4. No-upward birth for a complete coloured block

Let `tau` be a maximal coherent token in the current state. The X044 block for `tau` enrols every colour capable of appearing in its support, intersection, direction, passive, boundary, or source descendants. It performs simultaneous lower-dimensional preparation and then a characteristic-free monomial face word.

### Theorem 4.1 -- Coherent no-upward-birth theorem

Assume the complete-colour hypothesis and the lower-dimensional full-portfolio theorem. For every nonterminal chart successor of the completed block, every primitive event token `sigma` satisfies

```text
sigma <_coh tau.
```

Every unrelated pre-existing coherent token is transported with the same identity and a nonincreasing profile.

### Proof

The event support is contained in the locus on which hereditary transport and intrinsic recomputation fail to agree. The proof is by the colour carrying the first nonzero primitive event.

1. **Support-singular colour.** The event is supported on the singular reduced carrier, of strictly smaller dimension.
2. **Regular-support thickness colour.** The projectivized contact height drops by one on every surviving direction; if the direction disappears, support or Fitting complexity drops.
3. **Tor-Valabrega or passive colour.** Universal exactification and simultaneous preparation make the defining sequences universally exact. The generically zero defects vanish by flat-kill. Hence no event of the same passive profile survives.
4. **Active Hasse/Frobenius colour.** The complete normal-Hasse jet family is monomialized with the joint marked aggregate. A surviving active chart has lower marked/contact/Frobenius profile; complementary charts are terminal for this token.
5. **Trace/history colour.** The centre-exact transform is fully saturated and old exceptional copies retain the consumed ancestor ID. A nonexceptional trace factor or monomial-face height is deleted.
6. **Owner/arrangement colour.** Wonderful or toroidal serialization removes a maximal unresolved incidence layer. Any new intersection lies in a strictly lower prepared layer.
7. **Conormal/Fitting colour.** The projectivity discriminant or Schur-Fitting branch either moves to a projective chamber or lowers support/presentation/kernel profile.

If none of these coordinates decreased, every colour of the complete portfolio would lie in its good chamber, every defining comparison would be an isomorphism, and every admissible monomial face would already be discharged. Then hereditary transport equals intrinsic recomputation and the event cone is zero, contradicting the assumed primitive event.

### Corollary 4.2 -- Geometric birth trichotomy

Every nonzero coherent birth after a completed block is exactly one of:

```text
SOURCE_MERGE:
  the primitive support is a nontrivial join of incoming supports;

FINANCED_REAPPEARANCE:
  the source identity already exists and the same token returns with lower
  coherent profile;

EARLIER_GEOMETRIC_DROP:
  an earlier coordinate of rho_coh strictly decreases.
```

There is no free source birth attached merely to a new exceptional divisor.

## 5. Coherent recurrent-class termination

Let `Rec_coh(Sigma)` be the finite multiset of live coherent recurrence tokens, counted by canonical primitive identity rather than by chart copies.

### Theorem 5.1 -- Coherent multiset descent

For every completed maximal-token block and every nonterminal chart successor,

```text
Rec_coh(Sigma') <_DM Rec_coh(Sigma),
```

where `<_DM` is the Dershowitz--Manna multiset extension of `<_coh`.

### Proof

Remove from the old multiset the maximal tokens escaped by the simultaneous block. Unrelated tokens are transported unchanged or nonincreasingly. By Theorem 4.1 every genuinely new primitive token is strictly below one of the removed tokens. This is precisely the defining multiset replacement condition.

### Corollary 5.2 -- Finite coherent recurrent subgame

No infinite branch can consist only of coherent recurrence tokens. Equivalently, after finitely many completed blocks every branch is terminal or carries a genuine class-`V` noncoherent valuation/immediate-defect token.

### Ordinal realization

Choose an ordinal code `lambda_coh(tau)` compatible with `<_coh` and set

```text
Phi_coh(Sigma)=natural_sum_(tau in Rec_coh(Sigma)) omega^(lambda_coh(tau)).
```

Then every nonterminal coherent block strictly lowers `Phi_coh`.

## 6. Reduction to the immediate-defect frontier

The event complex of a finite coloured state has coherent cohomology on a finite model. Therefore it cannot itself be an exact coherent incarnation of an independent nonprincipal immediate-defect ramification cut. A class-`V` token must be carried separately by an immutable valuation/projection ancestry packet.

### Theorem 6.1 -- Coherent/noncoherent branch dichotomy

Assume semantic completeness of the finite coherent colour grammar. Every infinite branch has a tail on which at least one class-`V` token remains live. All coherent tokens on that tail are eventually removed or replaced by lower coherent tokens.

### Proof

If no class-`V` token occurs on a tail, the tail lies in the coherent recurrent subgame and contradicts Corollary 5.2.

### Remaining theorem UDE-EV

The missing assertion is now the following uniform event-visible defect escape theorem.

> Let a class-`V` token be represented by a quasi-compact valuation neighbourhood together with its finite event-visible coefficient, ramification, and source shadows on one common model. There exists one finite word of actual regular jointly legal centres, uniform on that neighbourhood, such that every leaf either becomes coherent/algebraizable, changes the pro-isomorphism class, or strictly lowers a nonresetting valuation coordinate.

Finite-stage approximation depth, a cofinal-tail counter, or a fixed-projection defect factor is not an allowed rank.
