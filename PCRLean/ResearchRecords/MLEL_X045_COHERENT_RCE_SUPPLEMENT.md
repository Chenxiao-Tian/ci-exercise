## 3. No-upward birth

Let a completed X044 block act on all maximal tokens of one coherent profile. A nonzero successor event must occur where at least one prepared colour fails to be inherited.

- A support-singular event has smaller carrier dimension.
- A regular-support thick event has smaller projective contact height or smaller support/Fitting profile.
- A passive event is impossible at the same profile after universal exactification and flat-kill.
- A direction event has smaller projective Hasse/contact profile.
- A trace event deletes a nonexceptional factor or is the same consumed source.
- An owner event has smaller building-set or incidence height.
- A conormal/Fitting event has smaller support or presentation profile.

If all profiles were unchanged, every prepared map would be an isomorphism and the event cone would be zero. Hence every primitive event is strictly lower than one of the escaped maximal tokens.


The multiset order is well founded. Therefore the coherent recurrent subgame has no infinite branch.
